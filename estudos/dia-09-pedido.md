# Dia 9 · O caminho de um pedido · 40 min

[Voltar para a trilha](01-TRILHA.md)

## Ler (15 min)

Abra [Plataforma Peça Já](../docs/PLATFORM.md).

Procure só isto:

- entrar na conta (`login`)
- pedidos (`list_orders`, `upsert_order`, `get_order`)
- lojas (`list_shops`)

Cada uma dessas palavras é uma ação que o app pede para a API. A API grava ou lê no banco.

## Perguntar ao Cursor (20 min)

Abra um chat novo neste projeto, cole o texto abaixo e envie. O pedido já diz para não alterar arquivo.

```text
Explica em português simples, como se eu não programasse.

Quero entender o caminho de um pedido no Peça Já.
Diga:
1. o que a pessoa vê no app
2. qual pedido a tela manda para a API
3. o que vai para o banco
4. o que acontece se der erro

Use o arquivo docs/PLATFORM.md como pista.
Não altere nenhum arquivo.
```

Leia a resposta e copie para o caderno a parte que você entendeu. Se uma frase ficar estranha, responda no mesmo chat: "explica de novo esta frase, com um exemplo de restaurante em Mucugê".

## Pronto quando

- [ ] A explicação do chat está resumida no caderno
