## O que anotar

- Git guarda o histórico do código no computador: cada commit é um ponto salvo.
- GitHub é o site onde esse histórico fica na internet, para não depender de um notebook só.
- O Peça Já usa isso. O Cursor mexe nos arquivos. O Git lembra o que mudou.
