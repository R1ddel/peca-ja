# FILA DE APROVAÇÕES (modelo)

Formato que todo agente usa para pedir sua decisão:

```
[URGÊNCIA: alta/média/baixa] [AGENTE: nome]
O QUE QUER FAZER:
POR QUÊ (impacto esperado):
RISCO / CUSTO:
RECOMENDAÇÃO:
PRAZO PARA DECIDIR:
Responda: APROVO / NÃO APROVO / AJUSTE: ...
```

Dica: responda tudo de uma vez no briefing da manhã.
